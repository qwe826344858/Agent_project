# 后端技术实现流程梳理（阶段一MVP）

状态：已完成

## 一、实施步骤总览

1. 初始化 FastAPI 工程骨架
2. 实现基础接口与健康检查
3. 打通 LLM 与搜索服务
4. 实现 `/api/chat` SSE 事件流
5. 完成日志、错误码与联调

## 二、详细流程

### 1. 工程初始化

1. 创建 `apps/backend` 目录结构（`app/api`、`app/services`、`app/core`）。
2. 增加配置管理（环境变量读取、配置校验）。
3. 增加统一日志中间件（requestId 注入）。

### 2. 接口落地

1. `GET /api/healthz`：服务健康检查。
2. `GET /api/suggestions`：返回推荐问题。
3. `POST /api/chat`：SSE 流式接口，按事件协议输出。

### 3. 业务编排落地

1. 完成意图识别服务。
2. 完成搜索词生成与搜索执行服务。
3. 完成答案生成服务与来源拼装。
4. 完成追问分支与拒答分支。

### 4. 联调与优化

1. 与前端对齐 SSE 事件顺序。
2. 增加上游故障降级逻辑。
3. 优化响应时延与错误提示可读性。

## 三、里程碑建议

1. M1：三大接口可访问
2. M2：`/api/chat` 可流式返回
3. M3：来源与免责声明完整输出
4. M4：性能达标并可发布
