# 后端技术方案设计（阶段一MVP）

状态：已完成

## 一、目标与范围

1. 提供稳定的问答主链路与流式输出能力。
2. 支撑搜索优先模式：意图识别 -> 搜索编排 -> 回答生成。
3. 建立可扩展编排层，后续可平滑迁移 LangGraph。

## 二、技术选型

1. 框架：FastAPI
2. 数据校验：Pydantic
3. LLM适配：LiteLLM（统一多模型调用）
4. 缓存/存储：Redis、PostgreSQL（阶段一可按需）
5. 部署：单一 `docker-compose.yml`

## 三、分层设计

1. Controller 层：HTTP/SSE 接口入口
2. Application 层：`chat()` 业务编排入口
3. Orchestrator Adapter：统一编排接口
4. Domain Services：
   - IntentService
   - QueryService
   - SearchService
   - AnswerService
   - LLMService
5. Infrastructure 层：外部API客户端、日志、配置

## 四、关键流程

1. `POST /api/chat` 接收问题并返回 SSE 流。
2. 意图识别判断是否需要追问。
3. 若可检索：生成关键词并发搜索，汇总摘要。
4. 生成回答正文，输出来源与免责声明。
5. 流结束输出 `done` 事件。

## 五、稳定性与安全

1. 上游调用超时与重试控制。
2. 统一错误码与 requestId 追踪。
3. 敏感配置走环境变量，不入库不落日志。
4. 合规边界由 Prompt 规则和输出检查共同保证。
