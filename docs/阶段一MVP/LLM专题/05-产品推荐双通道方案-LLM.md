# 产品推荐双通道方案 — LLM 部分

状态：待评审
关联文档：

- 前端部分：`前端专题/06-产品推荐双通道方案-前端.md`

## 一、概述

双通道方案中，LLM 的职责发生重大调整：

**变更前**：LLM 负责生成完整回答（含产品名称、价格、投保链接）
**变更后**：LLM **仅负责文字建议**（选购分析、对比、风险提示），产品卡片由代码逻辑生成

## 二、LLM 职责边界

### 2.1 LLM 负责（通道 B）

1. 根据用户条件和搜索结果生成**选购建议**
2. 产品之间的**对比分析**
3. **风险提示**和注意事项
4. 追问话术（信息不足时）
5. 超范围引导（非保险问题）

### 2.2 LLM 不再负责（移至通道 A）

1. ~~产品名称和保险公司~~ → 从平台搜索结果提取
2. ~~价格信息~~ → 从商品详情页抓取
3. ~~投保链接~~ → 从搜索结果的 URL 中提取
4. ~~产品标签~~ → 从搜索结果标题中提取

## 三、Prompt 变更

### 3.1 Answer Prompt 调整

变更 `ANSWER_PROMPT_TEMPLATE`，明确告知 LLM 不需要输出产品链接和价格：

```
【回答规则】
1. 必须基于检索结果回答，不得编造内容或来源。
2. 不需要输出产品链接和价格，这些信息由系统自动展示。
3. 专注于选购建议：对比分析、适用人群、注意事项。
4. 若搜索结果冲突，明确说明"不同来源存在差异"。
5. 先结论后解释，分点表达，简洁易懂。

请按以下结构输出（纯文本）：
【选购建议】
  根据用户条件给出 2-3 条针对性建议（如关注续保、免赔额、增值服务等）
【注意事项】
  投保时需要注意的风险点
```

### 3.2 去除产品推荐格式要求

变更前的 Prompt 包含以下格式要求（需删除）：

```
❌ 删除：
   产品名称：XXX
   保险公司：XXX
   参考保费：XXX元/年
   投保链接：XXX
```

### 3.3 System Prompt 补充

在 `SYSTEM_PROMPT` 中增加一条规则：

```
6. 不要在回答中输出投保链接或产品购买页面的 URL，系统会自动为用户展示真实的产品卡片。
```

## 四、意图识别调整

### 4.1 追问规则放宽

产品推荐意图下，只有同时缺少 2 个以上关键槽位才追问（已实现）：

| 场景 | 缺失槽位数 | 行为 |
|---|---|---|
| "24岁想买医疗险" | 缺 budget（1个） | **不追问**，直接推荐 |
| "推荐个保险" | 缺 age + budget + preference（3个） | 追问 |
| "想买重疾险，预算5000" | 缺 age（1个） | **不追问**，直接推荐 |

### 4.2 触发产品搜索的意图

以下意图触发通道 A（产品卡片）：
- `product_recommendation`
- `product_query`
- `comparison`

其他意图仅走通道 B（文字回答）。

## 五、LLM 输入变更

### 5.1 搜索上下文来源

> **变更（2026-03-25）**：通道A 改为平台直连 API，通道B 的通用搜索改为 fallback 静态知识库。LLM 不再依赖 MiniMax Search API 或 Open-WebSearch MCP 的搜索结果。

通道 B 的 LLM 接收的上下文来自**fallback 静态知识库**（预置的保险知识、常见问题解答），不包含平台商品数据。平台商品数据仅用于通道 A 的产品卡片。

```
通道A 平台直连 API → PlatformAPI    → 产品卡片（不传给 LLM）
通道B 静态知识库   → SearchService  → LLM 上下文（传给 LLM）
```

### 5.1.1 LLM 协议变更

- 从 Anthropic 协议切换到 **OpenAI 兼容协议**
- API 端点：`https://api.minimaxi.com/v1`
- 模型：`MiniMax-M2.5-highspeed`（在 `llm_providers.yaml` 中配置）
- 思维链过滤：模型输出的 `<think>...</think>` 标签在 `llm_client.py` 的 `call_text` 和 `call_text_stream` 中自动过滤，前端不会看到

### 5.2 temperature 参数

产品推荐场景建议降低 temperature，让输出更稳定：
- 意图识别：`0.2`（不变）
- 选购建议：`0.3`（从 0.4 降低，减少发散）
