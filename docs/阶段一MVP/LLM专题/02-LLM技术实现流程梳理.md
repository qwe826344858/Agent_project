# LLM技术实现流程梳理（阶段一MVP）

状态：已完成

## 一、实施步骤总览

1. 定义 Prompt 模板与输出格式
2. 实现 LLMClient 统一调用
3. 实现三段服务（意图/搜索词/答案）
4. 完成后端编排接入与错误处理
5. 完成效果评估与迭代

## 二、详细流程

### 1. Prompt 与 Schema

1. 编写 System Prompt 与任务 Prompt。
2. 为意图和搜索词输出定义严格 JSON Schema。
3. 增加边界规则与合规词限制。

### 2. 调用封装

1. 实现 `LLMClient`（超时、重试、日志）。
2. 封装 `call_json()` 与 `call_text()` 两类调用。
3. 统一错误映射（超时、限流、上游异常）。

### 3. 服务落地

1. IntentService：识别意图与缺失槽位。
2. QueryService：输出 3-5 个高质量检索词。
3. AnswerService：生成结构化回答正文。

### 4. 联调验证

1. 连接 SearchService，将检索摘要注入答案生成。
2. 校验追问路径与拒答路径。
3. 记录失败样例并迭代 Prompt。

## 三、里程碑建议

1. M1：三段服务可独立运行
2. M2：编排链路可端到端输出
3. M3：失败样例回放与优化闭环
