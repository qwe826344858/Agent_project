# 前端技术实现流程梳理（阶段一MVP）

状态：已完成

## 一、实施步骤总览

1. 初始化项目与基础依赖
2. 搭建页面骨架与核心组件
3. 接入后端接口与SSE解析
4. 完成状态、错误与来源展示
5. 联调与性能优化

## 二、详细流程

### 1. 初始化与工程约定

1. 创建 Next.js + TypeScript 项目。
2. 设定目录约定：`components/`、`lib/`、`types/`、`app/`。
3. 配置环境变量：`NEXT_PUBLIC_API_BASE_URL`。

### 2. 页面骨架搭建

1. 完成主页面布局（消息区 + 输入区 + 推荐问题区）。
2. 定义消息数据结构：
   - `role`（user/assistant）
   - `content`
   - `sources`
   - `status`

### 3. SSE 链路实现

1. 调用 `POST /api/chat` 建立流式读取。
2. 按行解析 `event` 与 `data`。
3. 根据事件分发到对应状态更新器。

### 4. 交互完善

1. 输入为空时禁发。
2. 请求中显示“思考中”状态。
3. 失败时展示错误文案与重试按钮。
4. 输出结束自动恢复输入可用状态。

### 5. 联调与优化

1. 与后端对齐事件顺序与字段。
2. 优化长文本渲染与滚动体验。
3. 保证移动端输入区域不遮挡消息。

## 三、里程碑建议

1. M1：页面静态版完成
2. M2：SSE链路可用
3. M3：来源与免责声明完整展示
4. M4：联调通过并可发布
