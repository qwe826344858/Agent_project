# 产品推荐双通道方案 — 前端部分

状态：待评审
关联文档：
- 后端部分：`后端专题/05-产品推荐双通道方案-后端.md`
- LLM部分：`LLM专题/05-产品推荐双通道方案-LLM.md`

## 一、概述

前端需支持双通道输出：产品卡片（结构化 JSON）与文字建议（流式文本）同时展示。

> **变更说明（2026-03-25）**：
> - 后端改为平台直连 API，`products` 事件已包含价格信息，无需骨架屏渐进式加载。
> - `products_update` 事件变为可选，通常不会推送。
> - 前端端口从 3000 改为 3001（3000 留给 MCP 服务）。
> - SSE 请求直连后端 8000 端口（不走 Next.js rewrites 代理，避免缓冲导致非流式）。

## 二、新增组件：ProductCardList

文件：`src/components/ProductCardList.tsx`

### 2.1 组件状态

1. **完整态**：收到 `products` 事件后直接渲染完整卡片（含价格）。平台直连 API 已返回结构化数据，无需骨架屏。
2. **兜底态**：若 `price` 为空（个别平台未返回价格），显示"查看详情"按钮。
3. **交互**：点击卡片跳转到投保链接（新窗口打开）。

> `products_update` 事件已变为可选。前端仍保留 `onProductsUpdate` 处理器以兼容后续扩展，但通常不会触发。

## 三、SSE 解析器变更

文件：`src/lib/sse-parser.ts`

新增 `products` 事件处理（`products_update` 保留但变为可选）：

```typescript
interface SSEHandlers {
    // 现有事件...
    onProducts?: (data: { items: ProductCard[] }) => void;
    onProductsUpdate?: (data: { items: Partial<ProductCard>[] }) => void;
}
```

`dispatchEvent` 函数中新增两个 case 分支。

## 四、ChatPage 状态管理变更

文件：`src/app/page.tsx`

```typescript
// 新增状态
const [products, setProducts] = useState<ProductCard[]>([]);

// products 事件：设置初始卡片列表
onProducts: (data) => {
    setProducts(data.items);
};

// products_update 事件：按 id 更新对应卡片的价格
onProductsUpdate: (data) => {
    setProducts(prev => prev.map(p => {
        const update = data.items.find(u => u.id === p.id);
        return update ? { ...p, ...update } : p;
    }));
};

// done 事件时清理 products（下一轮对话时重置）
// 在 handleSend 中重置：setProducts([]);
```

## 六、新增类型定义

文件：`src/types/chat.ts`

```typescript
/** 产品推荐卡片 */
export interface ProductCard {
    id: string;
    name: string;
    company: string;
    price: string | null;
    priceLabel: string;
    tags: string[];
    url: string;
    platform: string;
    brief: string;
}

/** SSE products 事件载荷 */
export interface SSEProductsPayload {
    items: ProductCard[];
}

/** SSE products_update 事件载荷 */
export interface SSEProductsUpdatePayload {
    items: Partial<ProductCard>[];
}
```

## 八、性能预估（前端视角）

| 事件 | 时间点 | 用户感知 |
|---|---|---|
| `products` | 平台 API 返回后 ~1-3s | 立即看到完整卡片（含价格，可点击跳转） |
| `delta` 开始 | ~3-5s | 文字建议开始流式输出 |
| `done` | ~15-20s | 全部完成 |

> **SSE 连接方式**：前端直连后端 8000 端口发送 SSE 请求，不走 Next.js rewrites 代理，避免代理缓冲导致流式输出变为批量输出。前端端口为 3001。
