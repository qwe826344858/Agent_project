## 模块详情

### M1：数据模型 + ChatRequest 扩展

- **文件**：`app/schemas/chat.py`
- **内容**：
  1. ChatRequest 新增 `action`、`product_url`(alias productUrl)、`product_name`(alias productName) 可选字段
  2. 新增 `DutyItem` 模型：name, coverage, description, is_optional
  3. 新增 `ProductDetail` 模型：product_name, product_url, platform, duties, cn_char_count, match_rate
- **测试**：`tests/test_schemas.py` — ChatRequest 新字段序列化、DutyItem/ProductDetail 构造

### M2：HTML 清洗模块

- **文件**：`app/services/html_cleaner.py`（新增）
- **内容**：
  1. `clean_html(raw_html: str) -> tuple[str, int]`：BeautifulSoup 清洗，返回(纯文本, 中文字符数)
  2. 删除 script/style/nav/footer/header/iframe/noscript/svg/img 标签
  3. 文本截断：≤5000 全文，5000-10000 取前 5000，>10000 取前 5000+末尾 1000
- **测试**：`tests/test_html_cleaner.py` — 标签清除、中文计数、截断策略、空 HTML

### M3：全局缓存模块

- **文件**：`app/services/product_detail_cache.py`（新增）
- **内容**：
  1. `ProductDetailCache` 类：dict 存储、线程锁、TTL 1 天
  2. `get(url)` / `set(url, detail)` / `clear_expired()`
  3. 模块级单例 `product_detail_cache`
- **测试**：`tests/test_product_detail_cache.py` — set/get、过期清理、未命中、并发安全

### M4：Prompt 常量

- **文件**：`app/services/prompts.py`（修改）
- **内容**：新增 3 个常量
  1. `DETAIL_EXTRACT_SYSTEM_PROMPT` — 提取专家角色
  2. `DETAIL_EXTRACT_PROMPT_TEMPLATE` — 从网页文本提取保障项 JSON
  3. `DETAIL_EXPLAIN_PROMPT_TEMPLATE` — 首次通俗解读
  4. `DETAIL_FOLLOWUP_PROMPT_TEMPLATE` — 追问回答
- **无独立测试**（在 M5 的 Skill 测试中覆盖）

### M5：ProductDetailSkill 主体

- **文件**：`app/services/product_detail_skill.py`（新增）
- **内容**：
  1. `ProductDetailSkill.run()` — async generator，yield SSE 事件
  2. `_fetch_page(url)` — httpx GET 网页
  3. `_extract_with_retry()` — LLM 提取 + 字符回查校验 + 最多 3 次重试
  4. `_parse_duties_json()` — JSON 解析为 DutyItem 列表
  5. `validate_extraction()` — 字符回查匹配率计算
  6. `_generate_answer()` — LLM 第 2 轮通俗翻译（流式）
- **测试**：`tests/test_product_detail_skill.py` — 校验逻辑、JSON 解析、降级处理

### M6：请求链路贯通

- **文件**：`app/api/chat.py`、`app/services/orchestrator_adapter.py`、`app/services/chat_orchestrator.py`
- **内容**：
  1. `chat.py`：message 校验放宽（有 action 时允许空）；传递 action/product_url/product_name
  2. `orchestrator_adapter.py`：run_chat_flow 签名新增参数并透传
  3. `chat_orchestrator.py`：run_stream 入口新增 action 路由分支
- **无独立测试**（在 M10 端到端验证中覆盖）

### M7：前端 api.ts + sse-parser 扩展

- **文件**：`src/lib/api.ts`、`src/lib/sse-parser.ts`、`src/types/chat.ts`
- **内容**：
  1. `api.ts`：SendChatMessageOptions 新增 action/productUrl/productName；请求体构造
  2. `sse-parser.ts`：SSEHandlers 新增 onDetailItems；dispatchEvent 路由
  3. `chat.ts`：新增 DutyItem 接口；ChatMessage 新增 duties 字段

### M8：前端组件

- **文件**：`src/components/ProductCard.tsx`（修改）、`src/components/DutyDetailCard.tsx`（新增）
- **内容**：
  1. ProductCard 新增"查看保障详情"按钮 + onViewDetail 回调
  2. DutyDetailCard 展示保障项列表（名称/额度/必选or可选）

### M9：前端 page.tsx 集成

- **文件**：`src/app/page.tsx`
- **内容**：
