## 二、整体方案

### 2.1 页面布局调整（P1）

**当前布局**：
```
┌───────────────────────┐
│ header                │
├───────────────────────┤
│ 消息流（含产品卡片）    │ ← 产品卡片嵌在消息里，会被滚走
│                       │
├───────────────────────┤
│ 输入框                │
└───────────────────────┘
```

**优化后布局**：
```
┌───────────────────────┐
│ header                │
├───────────────────────┤
│ 产品面板（吸顶）       │ ← 始终可见，横向滚动
│ [产品A] [产品B✅] [C]→ │    选中产品高亮
├───────────────────────┤
│ 消息流（纯文字对话）    │ ← 不含产品卡片
│                       │
├───────────────────────┤
│ 输入框                │
└───────────────────────┘
```

**关键规则**：
- 产品面板仅在当前对话有产品推荐时显示（无产品时隐藏）
- 新一轮推荐产品会替换面板内容（不追加）
- 面板高度固定（约 120px），不占用过多空间
- 消息流中的 `products` 事件不再渲染卡片，改为更新面板

### 2.2 产品选中状态（P2）

**前端新增状态**：

```typescript
// page.tsx
const [currentProducts, setCurrentProducts] = useState<ProductCard[]>([]);
const [selectedProduct, setSelectedProduct] = useState<{
  url: string;
  name: string;
} | null>(null);
```

**状态流转**：

```
① 用户提问"推荐百万医疗险"
    → onProducts 事件：setCurrentProducts(items)，面板显示
    → selectedProduct 保持 null

② 用户点击产品 B 的"查看保障详情"
    → setSelectedProduct({ url, name })
    → 产品 B 卡片高亮（蓝色边框 + ✅ 标记）
    → 发送 action: "product_detail"

③ 用户追问"免赔额怎么算"
    → 检测到 selectedProduct 非空
    → 自动附带 action: "product_followup" + productUrl
    → 后端从缓存读取保障数据 → LLM 回答

④ 用户提新问题"换一个重疾险推荐"
    → 走普通流程（无 action）
    → onProducts 事件：替换 currentProducts，清空 selectedProduct
```

**产品卡片选中样式**：

```typescript
// ProductCard.tsx
const isSelected = selectedUrl === product.url;

<div className={`product-card ${isSelected ? "ring-2 ring-blue-500" : ""}`}>
  {isSelected && (
    <div className="absolute top-2 right-2 bg-blue-500 text-white text-xs rounded-full px-1.5 py-0.5">
      已选中
    </div>
  )}
  ...
</div>
```

### 2.3 追问关联已选产品（P3）

**新增 action 类型**：`product_followup`

**前端逻辑**：

```typescript
// page.tsx handleSend 中

const handleSend = useCallback(async (message: string) => {
  // 如果有选中产品，追问时自动附带产品上下文
  const isFollowup = selectedProduct !== null;

  await sendChatMessage(message, handlers, {
    action: isFollowup ? "product_followup" : undefined,
    productUrl: isFollowup ? selectedProduct.url : undefined,
    productName: isFollowup ? selectedProduct.name : undefined,
  });
}, [selectedProduct]);
```

**后端编排器新增分支**：

```python
# chat_orchestrator.py

if action == "product_followup" and product_url:
    # 从缓存读取已提取的保障数据 → LLM 结合保障信息回答追问
    from app.services.product_detail_skill import ProductDetailSkill
    skill = ProductDetailSkill()
    async for event in skill.run(
        product_url=product_url,
        product_name=product_name or "",
        user_question=message,  # 用户的追问内容
    ):
        yield event
    yield {"event": "done", "data": {"requestId": request_id}}
    return
```

> `ProductDetailSkill.run()` 内部已实现：缓存命中 → 直接 LLM 回答（追问 Prompt），无需重新抓取。

**追问链路耗时**：

| 场景 | 链路 | LLM 轮数 | 耗时 |
|---|---|---|---|
| 缓存命中 | 读缓存 → LLM 追问 Prompt | 1 | 3-5s |
| 缓存未命中（极少）| 完整抓取链路 | 2 | 10-15s |

### 2.4 取消选中

用户可通过以下方式取消产品选中：
- 点击已选中的产品卡片 → 取消选中
- 新一轮产品推荐到达时 → 自动清空选中
- 用户输入无关产品的问题（无 selectedProduct 上下文）→ 走普通流程

## 六、验收标准

| 项目 | 标准 |
|---|---|
| 吸顶面板 | 产品卡片固定在消息流上方，滚动消息时不消失 |
| 无产品时 | 面板不显示，不占位 |
| 选中态 | 点击产品后蓝色边框 + "已选中"标记 |
| 取消选中 | 再次点击已选中产品可取消 |
| 新推荐覆盖 | 新一轮推荐产品替换面板，清空选中 |
| 追问关联 | 选中产品后追问自动携带 product_followup + productUrl |
| 缓存命中 | 追问响应 3-5s（1 轮 LLM） |
| 缓存未命中 | 自动走完整提取链路（降级，10-15s） |
| 消息流 | 不再渲染产品卡片，只有文字对话 |
| 回归 | 未选中产品时追问走普通流程，不影响原有逻辑 |
