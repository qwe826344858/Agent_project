## 一、现状分析

### 1.1 耗时拆解

当前完整链路耗时约 **17-21s**，拆解如下：

```
├── 意图识别 LLM 调用          ~3-5s
├── 平台 API 并行搜索          ~2-4s（3 平台并发）
├── LLM 流式生成文字建议       ~12-15s  ← 主要瓶颈
├── 来源/免责/done              <100ms
└── 总计                       ~17-21s
```

### 1.2 瓶颈定位

| 阶段 | 耗时占比 | 可优化空间 |
|---|---|---|
| 意图识别 | 20% | 中 — 可与产品搜索并行 |
| 平台搜索 | 15% | 低 — 已并发，受平台响应限制 |
| **LLM 文字生成** | **65%** | **高 — Prompt 精简 + 并行启动** |

## 二、优化方案

### 2.1 意图识别与产品搜索并行化

**当前**（串行）：
```
意图识别(3-5s) → 判断是否搜索 → 平台搜索(2-4s) → LLM 生成(12-15s)
总计: ~17-23s
```

**优化后**（部分并行）：
```
意图识别(3-5s) ─┐
                 ├→ LLM 生成(12-15s)
平台搜索(2-4s) ─┘→ 推送 products 事件
总计: ~15-20s（节省 2-4s）
```

**实现**：在编排器中，先并行启动意图识别和平台搜索，两个结果都就绪后再启动 LLM：

```python
async def run_stream(self, message, request_id=""):
    yield {"event": "status", "data": {"stage": "analyzing", "message": "正在分析您的问题..."}}

    # 并行：意图识别 + 平台搜索（乐观搜索，即使意图不是产品推荐也不浪费太多）
    intent_task = asyncio.create_task(intent_service.classify(message))
    products_task = asyncio.create_task(search_all_platforms(message))

    # 等待意图识别
    ctx.intent = await intent_task

    # 根据意图决定是否使用产品搜索结果
    need_products = ctx.intent.intent in _PRODUCT_SEARCH_INTENTS
    if need_products:
        ctx.products = await products_task
        if ctx.products:
            yield {"event": "products", "data": ...}
    else:
        products_task.cancel()  # 不需要产品时取消搜索

    # LLM 流式生成...
```

**代价**：非产品意图时浪费了一次平台搜索（~2-4s 并发 HTTP 请求，无 LLM 费用）。收益：产品推荐场景节省 3-5s。

**净收益**：产品推荐场景（~70% 流量）节省 3-5s，知识问答场景（~30%）无损。

### 2.2 LLM Prompt 精简化

**当前**：LLM 输出 434-846 字，需要 12-15s。
**目标**：控制在 **200-400 字**，预期 8-10s。

**变更文件**：`prompts.py` 的 `ANSWER_PROMPT_TEMPLATE`

新增输出长度约束：

```
【输出长度】
- 选购建议 2-3 条，每条不超过 80 字
- 注意事项 1-2 条，每条不超过 60 字
- 总字数控制在 200-400 字以内
- 不要重复用户已知信息（如年龄、预算）
```

### 2.3 首字节优化 — 产品卡片先行

**当前已实现**：产品卡片在 LLM 生成之前推送（`products` 事件先于 `delta`）。

**进一步优化**：在前端添加"正在为您分析..."过渡文案，让用户在等待 LLM 输出时有内容可看（产品卡片 + 加载提示），降低感知等待时间。

前端 `ThinkingStatus` 组件在 `answering` 阶段显示"正在生成建议，您可以先浏览上方产品..."：

```typescript
const STAGE_MESSAGES: Record<string, string> = {
    analyzing: "正在分析您的问题...",
    searching: "正在搜索保险产品...",
    answering: "正在生成选购建议，您可以先浏览上方产品...",  // 优化
};
```

| 项目 | 标准 |

| 回归 | 文字建议质量评分不低于 8.0/10 |
