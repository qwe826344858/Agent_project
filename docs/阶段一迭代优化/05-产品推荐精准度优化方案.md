## 一、问题复盘

### 1.1 根因分析

当前关键词提取链路：

```
用户输入 → base.py extract_keyword() → 正则匹配 KEYWORD_MAPPING → 搜索词
                                         ↓ 未命中
                                    返回 "保险"（兜底）
```

| 失败场景 | 用户输入 | 正则匹配结果 | 实际搜索词 | 预期搜索词 |
|---|---|---|---|---|
| 复合需求 | "全家人都配上保险" | 未命中 | "保险" | "医疗险"/"意外险"/"重疾险" |
| 人群定向 | "给宝宝买一份保险" | 未命中 | "保险" | "少儿医疗险"/"少儿重疾险" |
| 口语化表达 | "买个便宜点的保险" | 未命中 | "保险" | "意外险"/"医疗险" |
| 多险种组合 | "重疾险+百万医疗险的组合" | 仅命中"百万医疗" | "医疗" | ["重疾", "医疗"] |

**核心缺陷**：
1. `extract_keyword` 仅用正则匹配预设险种名，无法处理口语化/复合需求
2. 只返回**单个关键词**，无法发起多险种并行搜索
3. 兜底值"保险"过于宽泛，各平台返回随机品类

### 1.2 影响量化（来自评估报告）

| 角色 | 产品精准度 | 预算匹配度 | 根因 |
|---|---|---|---|
| 家庭主妇 | 4/10 | 2/10 | "保险"兜底 → 旅游险/责任险 |
| 宝妈 | 5/10 | 4/10 | "保险"兜底 → 车类运动/留学险 |
| 应届生 | 6/10 | 6/10 | "保险"兜底 → 混入无关品类 |
| 中年男人 | 8/10 | 8/10 | 命中"百万医疗"，但丢失"重疾" |

## 二、方案设计

### 2.1 总体架构

将关键词提取从"正则硬匹配"升级为**三层渐进策略**：

```
用户输入 → 第一层：多关键词正则提取（快，0ms）
         → 第二层：人群/场景 → 险种映射（快，0ms）
         → 第三层：兜底推断规则（快，0ms）
         → 合并去重 → 多关键词并行搜索
```

> **不引入额外 LLM 调用**——意图识别阶段已花 3-5s，关键词提取必须零延迟。

### 2.2 第一层：多关键词正则提取

**变更文件**：`base.py`

**当前**：`extract_keyword()` 返回 `str`（单个关键词）
**升级为**：`extract_keywords()` 返回 `list[str]`（多个关键词）

```python
# 扩展险种正则 — 覆盖更多口语化表达
INSURANCE_TYPE_RE = re.compile(
    r"(百万医疗|医疗保险|医疗险|医疗|"
    r"重疾险|重大疾病|重疾|"
    r"意外险|意外保障|意外|"
    r"寿险|定期寿险|终身寿险|"
    r"年金险|年金|养老险|养老金|"
    r"防癌险|防癌|"
    r"少儿险|儿童保险|儿童险|"
    r"教育金|教育险)"
)

def extract_keywords(self, user_input: str) -> list[str]:
    """从用户输入中提取多个搜索关键词"""
    matches = INSURANCE_TYPE_RE.findall(user_input)
    keywords = []
    seen = set()
    for raw in matches:
        mapped = KEYWORD_MAPPING.get(raw, raw)
        if mapped not in seen:
            seen.add(mapped)
            keywords.append(mapped)
    return keywords  # 可能为空，交给下一层处理
```

**效果**：
- "重疾险+百万医疗险的组合" → `["重疾", "医疗"]`（之前只取到"医疗"）

### 2.3 第二层：人群/场景 → 险种映射

新增 `AUDIENCE_MAPPING`，将用户描述中的人群/场景关键词映射为推荐险种：

```python
AUDIENCE_MAPPING: dict[str, list[str]] = {
    # 人群维度
    "宝宝": ["少儿医疗", "少儿重疾", "少儿意外"],
    "孩子": ["少儿医疗", "少儿重疾", "少儿意外"],
    "小孩": ["少儿医疗", "少儿重疾"],
    "儿童": ["少儿医疗", "少儿重疾"],
    "老人": ["医疗", "防癌", "意外"],
    "老年": ["医疗", "防癌", "意外"],
    "退休": ["医疗", "防癌", "养老"],
    "全家": ["医疗", "意外", "重疾"],
    "家庭": ["医疗", "意外", "重疾"],
    "父母": ["医疗", "防癌", "意外"],

    # 场景维度
    "住院": ["医疗", "百万医疗"],
    "生病": ["医疗", "重疾"],
    "看病": ["医疗"],
    "养老": ["年金", "养老"],
    "教育": ["教育金", "少儿重疾"],
    "猝死": ["意外", "寿险"],
    "身故": ["寿险", "意外"],
}

AUDIENCE_RE = re.compile("|".join(AUDIENCE_MAPPING.keys()))
```

**提取逻辑**：

```python
def _extract_audience_keywords(self, user_input: str) -> list[str]:
    """从人群/场景描述中推断险种关键词"""
    keywords = []
    seen = set()
    for match in AUDIENCE_RE.findall(user_input):
        for kw in AUDIENCE_MAPPING[match]:
            if kw not in seen:
                seen.add(kw)
                keywords.append(kw)
    return keywords
```

**效果**：
- "给宝宝买一份保险" → `["少儿医疗", "少儿重疾", "少儿意外"]`
- "全家人配保险" → `["医疗", "意外", "重疾"]`
- "退休了想买个医疗险" → 第一层已命中"医疗"，第二层补充"防癌""养老"

### 2.4 第三层：兜底推断规则

当前两层均无结果时，按用户预算/年龄推断合理险种：

```python
def _fallback_keywords(self, user_input: str) -> list[str]:
    """终极兜底：根据预算/年龄推断"""
    budget = _extract_budget(user_input)  # 复用已有预算提取
    age = _extract_age(user_input)

    if budget is not None:
        if budget <= 500:
            return ["意外", "医疗"]
        elif budget <= 3000:
            return ["医疗", "意外", "重疾"]
        else:
            return ["重疾", "医疗", "寿险"]

    if age is not None:
        if age < 18:
            return ["少儿医疗", "少儿意外"]
        elif age >= 55:
            return ["医疗", "防癌"]
        else:
            return ["医疗", "重疾", "意外"]

    # 真正的终极兜底（比"保险"精确）
    return ["医疗", "重疾", "意外"]
```

新增年龄提取工具：

```python
_AGE_RE = re.compile(r"(\d{1,2})\s*岁")

def _extract_age(user_input: str) -> Optional[int]:
    m = _AGE_RE.search(user_input)
    return int(m.group(1)) if m else None
```

### 2.5 多关键词并行搜索

**变更文件**：`__init__.py` 的 `search_all_platforms()`

当前每个平台只用**一个关键词**搜索。升级为：

```python
async def search_all_platforms(user_input: str, ...) -> list[ProductCard]:
    # 三层关键词提取
    kw_layer1 = PLATFORMS[0].extract_keywords(user_input)
    kw_layer2 = PLATFORMS[0]._extract_audience_keywords(user_input)
    kw_layer3 = [] if (kw_layer1 or kw_layer2) else PLATFORMS[0]._fallback_keywords(user_input)

    keywords = list(dict.fromkeys(kw_layer1 + kw_layer2 + kw_layer3))  # 去重保序
    keywords = keywords[:3]  # 最多 3 个关键词（控制并发量）

    logger.info("关键词提取: L1=%s L2=%s L3=%s → 最终=%s", kw_layer1, kw_layer2, kw_layer3, keywords)

    # 每个平台 × 每个关键词 = N 个并发任务
    tasks = []
    for platform in PLATFORMS:
        for kw in keywords:
            tasks.append(_safe_search(platform, kw, max_per_platform))

    results = await asyncio.gather(*tasks)
    # ... 合并去重 + 预算筛选（逻辑不变）
```

**并发量控制**：3 平台 × 3 关键词 = 最多 9 个并发请求（每个超时 10s），在可接受范围内。

### 2.6 搜索结果品类过滤

在合并去重之后、预算筛选之前，新增**品类过滤**步骤：

```python
# 无关品类黑名单
_IRRELEVANT_CATEGORIES = {
    "旅游险", "旅行险", "自驾游", "境外旅游",
    "航空意外", "交通意外",
    "责任险", "商业责任", "雇主责任",
    "财产险", "家财险",
    "车险", "运动保险", "车类运动",
    "留学", "签证",
    "宠物", "手机",
}

def _filter_irrelevant(products: list[ProductCard], keywords: list[str]) -> list[ProductCard]:
    """过滤与用户意图不相关的品类"""
    # 如果用户明确搜索旅游/交通等，则不过滤
    skip_filter = any(
        kw in ("旅游", "交通", "自驾", "留学", "运动") for kw in keywords
    )
    if skip_filter:
        return products

    filtered = []
    for p in products:
        name_and_tags = p.name + " ".join(p.tags)
        is_irrelevant = any(cat in name_and_tags for cat in _IRRELEVANT_CATEGORIES)
        if not is_irrelevant:
            filtered.append(p)

    removed = len(products) - len(filtered)
    if removed > 0:
        logger.info("品类过滤: 移除 %d 个不相关产品", removed)

    return filtered
```

## 三、预算筛选增强（P2）

### 3.1 最低价格门槛

**问题**：预算 500 时，0.2 元的交通意外险也被保留。

**方案**：增加下限过滤——产品年缴价格低于预算 10% 的，视为不相关：

```python
def _filter_by_budget(products, budget, tolerance=0.5):
    upper_bound = budget * (1 + tolerance)
    lower_bound = budget * 0.1  # 新增：最低价格门槛

    scored = []
    for p in products:
        annual = _estimate_annual_price(p.price)
        if annual is None:
            scored.append((999999, p))
            continue

        # 新增：低于预算 10% 的产品排除
        if annual < lower_bound:
            logger.debug("价格过低排除: %s (%.0f < %.0f)", p.name, annual, lower_bound)
            continue

        if annual <= upper_bound:
            diff = abs(annual - budget)
            scored.append((diff, p))
        # 超预算产品不再保留（之前会追加到末尾）

    scored.sort(key=lambda x: x[0])
    return [p for _, p in scored]
```

### 3.2 未指定预算时的默认排序

当用户未明确预算时（如"推荐百万医疗险"），按**综合热度**排序（平台默认排序），不做价格过滤，但仍然过滤无关品类。

## 四、小雨伞 company 字段补全（P3）

### 4.1 从产品名提取保险公司

**变更文件**：`xiaoyusan.py`

小雨伞产品名通常格式为"[品牌]产品名"或"公司名+产品名"：
- "众安保险众民保·百万医疗险2025"
- "[税优版]中国人保民享福终身护理保险"
- "中英人寿爱守护C款重大疾病保险"

```python
_COMPANY_PATTERNS = [
    r"(众安保险|众安)",
    r"(中国人保|人保)",
    r"(平安|中国平安)",
    r"(太平洋|太平洋保险)",
    r"(中国人寿|国寿)",
    r"(泰康|泰康人寿)",
    r"(新华保险|新华人寿)",
    r"(阳光保险|阳光人寿)",
    r"(中英人寿|中英)",
    r"(复星联合|复星)",
    r"(瑞华保险|瑞华)",
    r"(华贵保险|华贵人寿)",
    r"(中意人寿|中意)",
    r"(信泰人寿|信泰)",
    r"(百年人寿|百年)",
]
_COMPANY_RE = re.compile("|".join(f"(?:{p})" for p in _COMPANY_PATTERNS))

def _extract_company(product_name: str) -> str:
    m = _COMPANY_RE.search(product_name)
    return m.group(0) if m else ""
```

在 `search()` 中应用：

```python
company = _extract_company(title)  # 替代当前的 company=""
```
