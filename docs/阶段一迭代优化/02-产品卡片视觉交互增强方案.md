# 产品卡片视觉交互增强方案

状态：待评审
关联：阶段一 MVP `前端专题/06-产品推荐双通道方案-前端.md`

## 一、现状分析

### 1.1 当前实现

| 维度 | 现状 | 问题 |
|---|---|---|
| 入场动效 | 无，卡片瞬间出现 | 产品卡片是核心价值输出，缺乏视觉引导 |
| 卡片设计 | 白底灰边框，结构扁平 | 与普通消息气泡视觉层级无区分 |
| 悬浮交互 | 仅 `border-blue-300` + 微弱阴影 | 反馈不够明确，用户不确定是否可点击 |
| 价格展示 | 绿色文字，静态显示 | 价格是决策关键信息，缺乏视觉锚定 |
| 标签样式 | 蓝色浅底 pill | 单一颜色，无法区分标签类型 |
| 移动端 | 水平滚动，无滚动指示 | 用户不知道右侧还有更多卡片 |

### 1.2 目标效果

- 卡片入场有序列动画，视觉上"依次弹出"
- 卡片有明确的视觉层级（投影、渐变、图标）
- 悬浮/按下有清晰反馈，明确引导点击
- 价格区域突出，一眼可见
- 移动端有横向滚动指示

## 二、方案设计

### 2.1 卡片入场动效 — 交错淡入

产品卡片从 SSE `products` 事件推送，通常 1-5 张同时到达。使用 CSS `animation-delay` 实现交错入场：

```css
@keyframes card-enter {
    from {
        opacity: 0;
        transform: translateY(12px) scale(0.96);
    }
    to {
        opacity: 1;
        transform: translateY(0) scale(1);
    }
}
.product-card-enter {
    animation: card-enter 0.4s cubic-bezier(0.16, 1, 0.3, 1) both;
}
```

**交错延迟**：通过 `style` 属性传入 `animation-delay`：

```tsx
{products.map((product, index) => (
    <div
        key={product.id}
        className="product-card-enter"
        style={{ animationDelay: `${index * 120}ms` }}
    >
        <ProductCard product={product} />
    </div>
))}
```

> 120ms 间隔 × 5 张卡片 = 600ms 总入场时间，既有序列感又不拖沓。

#### 2.2.3 价格高亮区


**价格加载态**：保留脉冲骨架屏，增加微光扫过效果（shimmer）：

```css
@keyframes shimmer {
    0%   { background-position: -200px 0; }
    100% { background-position: 200px 0; }

.price-skeleton {
    height: 24px;
    width: 120px;
    border-radius: 6px;
    background: linear-gradient(90deg, #e5e7eb 0%, #f3f4f6 50%, #e5e7eb 100%);
    background-size: 400px 100%;
```


### 2.3 CTA 按钮升级

从文本链接升级为全宽按钮，增强点击引导：

```tsx
<a
    href={product.url}
    target="_blank"
    rel="noopener noreferrer"
    className="block w-full text-center py-2.5 mt-3
               bg-blue-500 hover:bg-blue-600 active:bg-blue-700
               text-white text-sm font-medium rounded-lg
               transition-colors duration-200"
    onClick={(e) => e.stopPropagation()}
>
    查看详情
    <span className="ml-1">→</span>
</a>
```

### 2.4 横向滚动增强

#### 2.4.1 渐变遮罩指示

当卡片列表超出可视区域时，右侧显示渐变遮罩提示"还有更多"：

```css
.product-list-wrapper {

}
.product-list-wrapper::after {
    content: '';
    position: absolute;
    right: 0;
    top: 0;
    bottom: 0;

    background: linear-gradient(to right, transparent, white);
    pointer-events: none;
    opacity: 1;
    transition: opacity 0.3s;
}
.product-list-wrapper.scrolled-end::after {
    opacity: 0;
}
```

#### 2.4.2 滚动位置检测

```typescript
const handleScroll = (e: React.UIEvent<HTMLDivElement>) => {

    const atEnd = el.scrollLeft + el.clientWidth >= el.scrollWidth - 10;
    setScrolledEnd(atEnd);
};
```

### 2.5 卡片数量徽标

在卡片列表上方显示数量信息，帮助用户了解推荐规模：


### 2.6 空结果友好提示

当平台 API 未返回产品（网络异常或无匹配结果）时，显示空状态：

```tsx
{products.length === 0 && !isStreaming && (
    <div className="text-center py-4 text-gray-400 text-sm">
        暂未找到匹配的产品，请尝试调整描述
    </div>
)}
```

## 五、动效参数速查

| 动效 | 时长 | 缓动 | 触发时机 |
|---|---|---|---|
| 卡片入场 | 400ms | `cubic-bezier(0.16, 1, 0.3, 1)` | `products` 事件到达 |
| 交错延迟 | 每张 +120ms | — | 按 index 计算 |
| 悬浮上移 | 250ms | `ease-in-out` | 鼠标 hover |
| 按下缩放 | 100ms | `ease-in-out` | 鼠标 active |
| 价格骨架 shimmer | 1500ms | `linear` 循环 | 价格为空时 |
| 渐变遮罩消失 | 300ms | `ease` | 滚动到末尾 |

## 六、验收标准

| 项目 | 标准 |
|---|---|
| 入场动效 | 卡片依次淡入上滑，间隔约 120ms，总时长 < 1s |
| 悬浮反馈 | hover 时上移 2px + 蓝色投影，视觉上明确"可点击" |
| 按下反馈 | active 时微缩至 0.98，有按钮按下感 |
| 价格高亮 | 绿色渐变背景区分于卡片其他区域 |
| 标签颜色 | 至少 5 种标签颜色映射，未知标签使用灰色兜底 |
| CTA 按钮 | 全宽蓝色按钮，hover/active 有颜色变化 |
| 横向滚动 | 超出时右侧渐变遮罩，滚到底部遮罩消失 |
| 移动端 | 触摸滑动流畅，卡片宽度适配（min-w-[260px]） |
| 性能 | 5 张卡片入场动画总帧率 > 55fps |
