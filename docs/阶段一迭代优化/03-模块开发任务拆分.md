## 二、任务详情

### T1：MarkdownRenderer 组件 + 样式

**输入文档**：`01-文本流式渲染优化方案.md` 第二节 2.1

**交付物**：
- `src/components/MarkdownRenderer.tsx`
- `globals.css` 新增 `.markdown-body` 样式规则
- `package.json` 新增 `react-markdown`、`remark-gfm` 依赖

**验收**：
- 输入 `**加粗** - 列表 > 引用 | 表格 |` 正确渲染
- 流式输入中途的不完整 Markdown 不崩溃

---

### T2：流式光标 + 逐段淡入动效

**输入文档**：`01-文本流式渲染优化方案.md` 第二节 2.2、2.3

**交付物**：
- `StreamingCursor` 子组件（可内联在 MarkdownRenderer 中）
- `globals.css` 新增 `cursor-blink`、`fade-in-up` 动画

**验收**：
- 蓝色方块光标在文字末尾 1s 周期闪烁
- 流式结束后光标消失
- 新段落出现时有 0.3s 淡入上滑

---

### T3：自动滚动优化

**输入文档**：`01-文本流式渲染优化方案.md` 第二节 2.4

**交付物**：
- `page.tsx` 修改：滚动节流（100ms）+ 用户上滚暂停逻辑

**验收**：
- 流式输出时自动跟随底部
- 用户手动上滚后不再自动拉回
- 用户滚回底部后恢复自动跟随

---

### T4：ProductCard 组件拆分 + 视觉重设计

**输入文档**：`02-产品卡片视觉交互增强方案.md` 第二节 2.2、第三节

**交付物**：
- `src/components/ProductCard.tsx`（从 ProductCardList 拆出）
- `src/components/ProductCardList.tsx`（重构为列表容器）
- `globals.css` 新增卡片投影、价格高亮、标签分色、shimmer 样式

**验收**：
- 卡片有分层投影，悬浮上移 2px + 蓝色阴影
- 按下微缩至 0.98
- 价格区域绿色渐变背景
- 标签根据内容自动匹配颜色
- CTA 全宽蓝色按钮

---

### T5：卡片入场交错动效

**输入文档**：`02-产品卡片视觉交互增强方案.md` 第二节 2.1

**交付物**：
- `globals.css` 新增 `card-enter` 动画
- `ProductCardList.tsx` 中 `animationDelay` 逻辑

**验收**：
- 5 张卡片依次入场，间隔 120ms
- 动画为淡入 + 上滑 + 微放大
- 动画结束后卡片停留在最终位置

---

### T6：横向滚动增强

**输入文档**：`02-产品卡片视觉交互增强方案.md` 第二节 2.4

**交付物**：
- `ProductCardList.tsx` 渐变遮罩 + 滚动位置检测
- `globals.css` 滚动条美化样式

**验收**：
- 超出时右侧渐变遮罩可见
- 滚动到末尾遮罩消失
- 滚动条细化美化（4px 高度）

---

### T7：ChatMessageList 集成 + 联调

**依赖**：T1、T2、T4 完成

**交付物**：
- `ChatMessageList.tsx` 中 AssistantBubble 使用 MarkdownRenderer
- 助手消息气泡宽度调整为 `max-w-[85%]`
- 产品卡片区使用新的 ProductCardList + ProductCard
- 确保产品卡片在文字之前、来源链接之前的正确位置

**验收**：
- 完整对话流程：发送问题 → 产品卡片入场 → 文字 Markdown 流式渲染 → 来源/免责
- 移动端布局不破坏
- 无控制台错误

---

### T8：全量验收测试

**验收清单**：

| 场景 | 检查项 |
|---|---|
| 产品推荐问题 | 卡片入场动效 + Markdown 文字流式 + 来源链接 |
| 知识问答 | 无卡片，Markdown 文字流式正常 |
| 追问对话 | 上一轮卡片保留，新一轮正常入场 |
| 移动端 | 卡片横向滑动、文字表格横向滚动 |
| 快速连续提问 | 旧回答中断，新回答正常渲染 |
| 网络异常 | 错误状态显示正常，不遗留动画残影 |
