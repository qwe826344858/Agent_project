## 二、功能点详细定义与验收标准

### F01 健康检查接口

- **接口**：`GET /api/healthz`
- **验收**：返回 200，body 含 `status: "ok"`、`service: "backend"`、`time`
- **自动化**：`test_healthz.py`（2 个用例）

### F02 推荐问题接口

- **接口**：`GET /api/suggestions`
- **验收**：返回 200，`suggestions` 数组 3-5 项
- **自动化**：`test_suggestions.py`（2 个用例）

### F03 SSE 事件流协议

- **接口**：`POST /api/chat`，Accept: text/event-stream
- **验收事件序列**：`status → products(可选) → status → delta×N → sources → disclaimer → done`
- **验收字段**：每个事件的 data 字段符合 `接口定义.md`
- **自动化**：
  - 后端 `test_chat.py`（6 个用例：正常流、空消息、缺字段、超范围、追问、上游错误）
  - 前端 `sse-parser.test.ts`（18 个用例：行解析、事件分发、跨 chunk、JSON 错误）

### F04 意图识别

- **入口**：`intent_service.classify(message)`
- **验收意图枚举**：knowledge_explain / product_recommendation / product_query / comparison / clause_explain / underwriting_basic / out_of_scope
- **验收规则**：
  - 含预算 + 险种名 → product_recommendation（即使疑问句）
  - "A和B有什么区别" → knowledge_explain 或 comparison（非推荐）
  - 非保险问题 → out_of_scope
- **自动化**：`test_llm_services.py::TestIntentService`（3 个用例）

### F05 搜索词生成

- **入口**：`query_service.generate(message, intent)`
- **验收**：返回 3-5 个关键词，推荐类含当年年份
- **自动化**：`test_llm_services.py::TestQueryService`（2 个用例）

### F06 LLM 流式回答

- **入口**：`answer_service.generate_stream(message, intent, search_results)`
- **验收**：
  - 流式输出 `delta` 事件
  - 内容含【选购建议】和【注意事项】
  - 不含产品链接和具体价格数字
  - 总字数 200-400 字
  - 无 `<think>` 标签泄露
- **自动化**：`test_llm_services.py::TestAnswerService`（2 个用例，不含长度和 think 验证）
- **人工验证**：实际对话检查格式和内容质量

### F07 输入校验与错误处理

- **验收**：空消息返回 400，缺字段返回 422，上游异常返回 error 事件
- **自动化**：`test_chat.py`（3 个用例）

### F08 超范围 / 追问处理

- **验收**：
  - 非保险问题 → "我目前专注于保险咨询..."
  - 缺关键信息 → 追问话术
- **自动化**：`test_chat.py`（2 个用例）

### F09 平台 API — 小雨伞

- **接口**：`POST https://www.xiaoyusan.com/index/searchData`
- **验收**：搜索"医疗"返回产品列表，含 name/price/url/tags/brief
- **company 补全**：产品名含保险公司时自动提取
- **自动化**：`test_company_extraction.py`（10 个用例，仅覆盖 company 提取）
- **人工验证**：发真实请求检查返回数据

### F10 平台 API — 平安

- **接口**：`GET https://baoxian.pingan.com/pa18shopnst/do/era/shopProduct/search`
- **验收**：搜索"医疗险"返回产品列表，含 name/price/url/brief
- **人工验证**：发真实请求检查返回数据

### F11 平台 API — 慧择

- **接口**：`POST https://search.huize.com/api/v4/pc/search/product/list`
- **验收**：搜索"医疗"返回产品列表，价格单位分→元转换正确
- **人工验证**：发真实请求检查返回数据

### F12 双通道编排（产品 + LLM 并行）

- **入口**：`chat_orchestrator.run_stream(message)`
- **验收**：
  - 产品推荐意图：先推送 `products` 事件，再流式 `delta`
  - 知识问答意图：无 `products` 事件，只有 `delta`
  - 意图识别与平台搜索并行执行（M4）
  - LLM 超时时降级为提示文案
- **人工验证**：端到端对话，检查事件顺序

### F13 预算提取与筛选

- **验收**：
  - "预算1000元" → 1000、"一年1万块" → 10000、"不超过500块" → 500
  - 产品价格低于预算 10%（家庭 5%）排除
  - 产品价格高于预算 150% 排除
  - 家庭场景按人均分摊后再过滤
- **自动化**：`test_family_budget.py`（13 个用例）

### F14 Think 标签过滤

- **入口**：`llm_client.call_text_stream()` / `call_text()`
- **验收**：LLM 输出的 `<think>...</think>` 在流式和非流式模式下均被过滤
- **人工验证**：前端对话不出现 think 内容

### F15 前端 SSE 解析

- **入口**：`sse-parser.ts`
- **验收**：正确解析 event/data 行、处理跨 chunk 拆分、JSON 失败调 onError
- **自动化**：`sse-parser.test.ts`（18 个用例）

### F16 前端消息渲染

- **验收**：
  - 用户消息右对齐蓝色气泡
  - 助手消息左对齐白色气泡
  - 产品卡片在文字之前展示
  - 来源链接在气泡下方
  - 免责声明在来源下方
  - 自动滚动到最新消息
- **人工验证**：浏览器实际查看

### F17 Markdown 渲染

- **入口**：`MarkdownRenderer.tsx`
- **验收**：LLM 输出的 `**加粗**`、`- 列表`、`> 引用`、`| 表格 |` 正确渲染
- **人工验证**：浏览器检查渲染效果

### F18 流式光标动效

- **验收**：蓝色方块光标在文字末尾 1s 周期闪烁，流式结束后消失
- **人工验证**：浏览器观察

### F19 产品卡片视觉交互

- **验收**：
  - 卡片有分层投影
  - hover 上移 2px + 蓝色阴影
  - active 微缩 0.98
  - 价格区域绿色渐变背景
  - 标签根据内容自动分色
  - CTA 全宽蓝色按钮
- **人工验证**：浏览器操作

### F20 卡片入场动效

- **验收**：卡片依次淡入上滑，间隔约 120ms
- **人工验证**：浏览器观察

### F21 横向滚动增强

- **验收**：超出时右侧渐变遮罩，滚到底部遮罩消失，滚动条 4px 细化
- **人工验证**：浏览器操作

### F22 多关键词提取引擎

- **入口**：`PlatformAPI.extract_keywords(user_input)`
- **验收**：
  - "重疾险+百万医疗" → `["重疾", "医疗"]`
  - "给宝宝买保险" → 含 "少儿医疗"
  - "全家保险规划" → 含 "医疗", "意外", "重疾"
  - 兜底返回 `["医疗", "重疾", "意外"]`
- **自动化**：`test_keyword_extraction.py`（76 个用例）

### F23 人群/场景 → 险种映射

- **验收**：宝宝→少儿险、老人→防癌+意外、全家→医疗+意外+重疾
- **自动化**：`test_keyword_extraction.py::TestAudienceKeywords`（10 个用例）

### F24 品类过滤

- **验收**：搜索"医疗"不返回旅游险/运动险/责任险
- **人工验证**：端到端对话检查产品列表

### F25 年龄适配过滤

- **验收**：
  - 成人不出现少儿/老年产品
  - 关键词推断：大学生/骑手/自由职业 → 成人
  - 家庭场景不过滤
- **人工验证**：端到端对话检查产品列表

### F26 家庭预算分摊

- **入口**：`_detect_family_size(user_input)`
- **验收**：
  - "两个孩子" → 4 人（含夫妻）
  - 总预算 ÷ 家庭人数 = 人均预算
  - 非家庭场景不分摊
- **自动化**：`test_family_budget.py`（13 个用例）

### F27 小雨伞 company 补全

- **验收**："众安保险众民保" → company="众安保险"
- **自动化**：`test_company_extraction.py`（10 个用例）

### F28 意图/搜索并行化

- **验收**：products 事件在意图识别完成后即推送（不等 LLM）
- **人工验证**：对话中观察产品卡片出现时机

### F29 Prompt 精简

- **验收**：LLM 输出文字 ≤ 400 字，含【选购建议】+【注意事项】
- **人工验证**：端到端对话检查输出长度

### F30 answering 阶段提示文案

- **验收**：`ThinkingStatus` 的 answering 显示"正在生成选购建议，您可以先浏览上方产品..."
- **人工验证**：浏览器观察

### 每个场景的验收检查项

- [ ] 产品数量 ≥ 1（推荐意图）/ = 0（知识意图）
- [ ] 产品无明显不相关品类（旅游/运动/责任险）
- [ ] 产品无年龄不匹配（成人不含少儿/老年产品）
- [ ] 有预算时，产品价格在合理区间
- [ ] 文字包含 Markdown 格式
- [ ] 文字长度 200-400 字
- [ ] 含来源 + 免责声明
- [ ] 事件序列完整（status → products → delta → sources → disclaimer → done）
- [ ] 无 `<think>` 标签泄露
- [ ] 无 error 事件
