## 模块详情

### M1：多关键词提取引擎

- **文件**：`apps/backend/app/services/platform_apis/base.py`
- **输入**：用户原始输入字符串
- **输出**：`list[str]` 搜索关键词列表（1-3 个）
- **内容**：
  1. `extract_keywords()` 替代 `extract_keyword()`，返回多关键词
  2. 扩展 `INSURANCE_TYPE_RE` 正则覆盖更多口语表达
  3. 新增 `AUDIENCE_MAPPING` + `_extract_audience_keywords()`
  4. 新增 `_fallback_keywords()` + `_extract_age()`
  5. 保留旧 `extract_keyword()` 兼容（内部调用新方法取第一个）
- **验收**：
  - "重疾险+百万医疗" → `["重疾", "医疗"]`
  - "给宝宝买保险" → `["少儿医疗", "少儿重疾", "少儿意外"]`
  - "全家保险规划" → `["医疗", "意外", "重疾"]`
  - "买个便宜的保险，预算500" → `["意外", "医疗"]`

### M2：多关键词并行搜索 + 品类过滤 + 预算增强

- **文件**：`apps/backend/app/services/platform_apis/__init__.py`
- **依赖**：M1 的 `extract_keywords()` 接口
- **内容**：
  1. `search_all_platforms()` 改用 `extract_keywords()` 获取多关键词
  2. 每个平台 × 每个关键词 并发搜索（最多 3×3=9 并发）
  3. 新增 `_filter_irrelevant()` 品类黑名单过滤
  4. `_filter_by_budget()` 增加 `lower_bound = budget * 0.1` 下限
  5. 超预算产品不再追加到末尾
- **验收**：
  - 搜索"医疗"不返回旅游险/运动险/责任险
  - 预算 500 时，0.2 元产品被过滤
  - 3 关键词搜索产品来源更多样

### M3：小雨伞 company 字段补全

- **文件**：`apps/backend/app/services/platform_apis/xiaoyusan.py`
- **内容**：
  1. 新增 `_COMPANY_RE` 正则和 `_extract_company()` 函数
  2. 在 `search()` 中用 `_extract_company(title)` 替代 `company=""`
- **验收**：
  - "众安保险众民保·百万医疗险" → company="众安保险"
  - "中国人保金医保3号" → company="中国人保"
  - 未匹配的产品 company 保持空字符串

### M4：意图识别与平台搜索并行化

- **文件**：`apps/backend/app/services/chat_orchestrator.py`
- **内容**：
  1. `asyncio.create_task` 并行启动意图识别和平台搜索
  2. 意图识别完成后判断是否需要产品，不需要时 `cancel()` 搜索任务
  3. 产品搜索结果就绪后立即推送 `products` 事件
- **验收**：
  - 产品推荐场景：products 事件在意图识别完成后 1s 内推送
  - 知识问答场景：不推送 products 事件，搜索任务被取消

### M5：Prompt 精简

- **文件**：`apps/backend/app/services/prompts.py`
- **内容**：
  1. `ANSWER_PROMPT_TEMPLATE` 增加输出长度约束（200-400 字）
  2. 增加"不重复用户已知信息"指令
- **验收**：
  - LLM 输出文字 ≤ 400 字
  - 建议质量不降（仍含选购建议 + 注意事项）

### M6：前端 answering 阶段提示文案

- **文件**：`apps/frontend/src/components/ThinkingStatus.tsx`
- **内容**：
  1. answering 阶段提示改为"正在生成选购建议，您可以先浏览上方产品..."
- **验收**：
  - 产品卡片展示后，answering 状态显示引导文案
